Six verbs.

Name a symbol as Name, Owner.member, path.dart:name or path.dart:LINE. Every verb takes --json and --limit N.

find

Where something is declared. Top-level declarations before members, library code before tests. Instant, no analyzer needed.

find Storefind Wallets.sandbox

show

A file's outline with importers and provider uses; a directory's pages, providers and notes; a symbol's signature, subtypes, overrides and use counts; a provider's readers by role.

show lib/core/session.dartshow lib/features/paymentshow FeatureKey

refs

Every use, with its line and role: ref.watch, ref.read, override, call, construct, implement, named argument. Includes test, tool and path-package code.

refs sessionProviderrefs Store.save

impact

What uses a symbol or file, one step further, and the tests that reach it. With --diff, seeded from the declarations your change touches.

impact walletKeyimpact --diff --base main

rename

A complete edit set from the element model: override sets, fields with their this. and super. parameters and named arguments, classes with their constructors. Verified after applying.

rename Base.label caption--apply

why

The import path from one file to another, with the line of each step.

why home_page.dart session.dart

Complete, or refused with a reason.

A rename waits until the whole workspace is analyzed, checks every edit against the text on disk, applies the edits in one staged step, then re-analyzes the edited files and their importers. A new error restores every file.

  • UNSAFE: dynamic calls to the name, framework overrides, code generation, public API of a publishable package, privacy changes, collisions
  • UNSUPPORTED: a kind it cannot compute yet; renaming by hand is fine
  • Warnings for string literals, enum names stored as data, and edited generated files

Install once per machine.

A background worker per checkout keeps the analyzer warm, exits after 20 idle minutes, and at most two run at once. Its cache lives outside your repository.

1dart pub global activate -sgit https://github.com/ArinFaraj/codegraph
2~/.pub-cache/bin/codegraph install-native
3codegraph refs YourClass

Put ~/.local/bin before ~/.pub-cache/bin on PATH. Agent setup: docs/agents.md.
